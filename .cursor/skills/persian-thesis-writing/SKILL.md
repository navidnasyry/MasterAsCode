# نگارش پایان‌نامه فارسی (IUT)

## پیش‌نیاز

قبل از ویرایش متن، فایل‌های `.tex` مرتبط و `dict_acn.tex` را بخوان تا اصطلاحات تعریف‌شده و سبک فعلی پروژه حفظ شود.

## اصول کلی نگارش

### لحن و دیدگاه

- **رسمی و علمی**؛ از زبان محاوره‌ای، شعار و اغراق پرهیز کن.
- **سوم‌شخص / بی‌طرف**: «پژوهش حاضر»، «در این پایان‌نامه»، «نتایج نشان می‌دهد» — نه «من» / «ما» (مگر در تشکر و قدردانی).
- **فعلی یا ساده گذشته** برای شرح کار انجام‌شده؛ **حال اخباری** برای حقایق پایدار.
- جملات **کوتاه تا متوسط**؛ هر پاراگراف یک ایده اصلی.

### واژگان و یکنواختی

| ترجیح | پرهیز |
|-------|-------|
| پایان‌نامه | پایان نامه، تز |
| پژوهش حاضر / این پژوهش | تحقیق من |
| دوقلوی دیجیتال | Digital Twin (بدون `\lr`) |
| فرآیند، سامانه، داده | فرایند (مگر در نام اختصاصی) |
| به‌صورت، به‌منظور، به‌ویژه | بصورت، بمنظور |
| بی‌درنگ، چندعاملی | real-time (در متن فارسی) |

اصطلاحات تخصصی را **یکبار** در `dict_acn.tex` تعریف و سپس با `\gls{}` / `\glspl{}` به‌کار ببر.

### نیم‌فاصله و نشانه‌گذاری

- نیم‌فاصله (`‌`) در: می‌شود، نمی‌توان، پایان‌نامه، چندعاملی، بی‌درنگ، به‌روزرسانی، سه‌بعدی.
- **ویرگول و نقطه فارسی** (`،` `۔`) در متن فارسی؛ نقطه لاتین فقط در `\lr{}`.
- **فاصله قبل از `\cite`**: یک فاصله قبل از `\cite{...}` بگذار.
- اعداد **فارسی** در متن عادی؛ اعداد **لاتین** داخل `\lr{}`، فرمول، نام dataset و ارجاع bibliographic.
- **واو ربط بعد از ویرگول یا نقطه‌ویرگول ممنوع است.** بلافاصله پس از `،` یا `؛` از «و» استفاده نکن. در فهرست، ویرگول میان اقلام می‌آید و «و» فقط پیش از مورد آخر — بدون ویرگول قبل از آن. پس از `؛` جملهٔ بعد را بدون «و» آغاز کن.

| نادرست | درست |
|--------|------|
| الف، ب، و پ | الف، ب و پ |
| الف؛ و ب | الف؛ ب |

### ساختار فصول (الگوی IUT)

```
فصل ۱ — مقدمه
  ├── بیان مسئله و ضرورت پژوهش
  ├── اهمیت پژوهش
  ├── اهداف پژوهش (کلی / اختصاصی)
  ├── محدودیت‌های پژوهش
  └── خلاصه فصول

فصل ۲ — ادبیات و مبانی نظری
فصل ۳ — روش‌شناسی
فصل ۴ — پیاده‌سازی / آزمایش
فصل ۵ — ارزیابی و نتیجه‌گیری
```

**خلاصه فصول**: هر فصل با «در **فصل …**، …» آغاز شود؛ جمع‌بندی با «در مجموع، …».

## قراردادهای LaTeX این پروژه

| مورد | دستور |
|------|-------|
| واژه/اختصار تعریف‌شده | `\gls{key}` / `\glspl{key}` |
| بدون پانویس (چکیده) | `\gls*{key}` |
| متن لاتین در خط | `\lr{...}` |
| ارجاع | `\cite{key}` یا `\cite{a,b,c}` |
| شکل/جدول | `\ref{fig:...}` / `\ref{tab:...}` |
| فرمول | `\eqref{eq:...}` |
| عنوان فصل | `\chapter{...}` |
| بخش | `\section{...}` / `\subsection{...}` |
| زیربخش بدون شماره | `\subsection*{...}` |

### چکیده فارسی

- `\subsection*{چکیده}`؛ `\baselineskip=0.7cm`
- **کلمات کلیدی**: `\noindent\textbf{کلمات کلیدی:}` سپس `1-واژه، 2-واژه، …`

### فهرست و عناوین

- `\SepMark{-}` → شماره بخش‌ها با خط تیره (مثلاً ۲-۱)
- `\indentfirst` → تورفتگی اول پاراگراف
- عناوین `\section` / `\subsection`: `\scshape\bfseries`

### شکل و جدول

```latex
\begin{figure}[H]
  \centering
  \includegraphics[width=0.85\textwidth]{images/...}
  \caption{عنوان فارسی \cite{key}}
  \label{fig:topic-name}
\end{figure}
```

- در متن: «در شکل \ref{fig:...}» / «همان‌طور که در شکل … نشان داده شده است»
- برچسب‌ها: `fig:` / `tab:` / `eq:` + نام کوتاه انگلیسی

### فهرست‌ها

```latex
\begin{enumerate}
  \item \textbf{عنوان}: توضیح...
\end{enumerate}
```

برای فهرست توضیحی با عنوان بولد: محیط `descitemize` (تعریف در `preamble.tex`).

## الگوهای جمله‌بندی (از پروژه)

**معرفی مسئله:**
> در …، … یکی از عوامل اصلی … محسوب می‌شود. … می‌توان در … دانست \cite{...}.

**اهداف:**
> اهداف این پژوهش در دو سطح کلی و اختصاصی به شرح زیر است:

**ارجاع به فصل:**
> در **فصل سوم**، روش‌شناسی پژوهش و معماری پیشنهادی ارائه می‌شود.

**جمع‌بندی:**
> در مجموع، این پژوهش با … تلاش دارد چارچوبی … ارائه دهد.

## چک‌لیست قبل از تحویل

- [ ] اصطلاحات با `\gls` / `\lr` یکنواخت‌اند
- [ ] نیم‌فاصله در پسوندها و مرکب‌ها رعایت شده
- [ ] بعد از `،` یا `؛` واو ربط نیامده (`، و` / `؛ و` حذف شده)
- [ ] `\cite` و `\ref` قبل از نقطه/ویرگول آمده‌اند
- [ ] هر `\gls{key}` در `dict_acn.tex` تعریف شده
- [ ] caption شکل‌ها/جداول فارسی و گویاست
- [ ] لحن سوم‌شخص و رسمی است
- [ ] پاراگراف‌ها با `\indent` یا `\noindent` آگاهانه شروع می‌شوند
- [ ] فصل ۱ «خلاصه فصول» با همه فصول هماهنگ است
